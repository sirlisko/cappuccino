# Can I have a cappuccino?

The Italian verdict on whether you may order a cappuccino right now, updated every minute.

**[cappuccino.sirlisko.com](https://cappuccino.sirlisko.com)**

In memory of the original by [raibaz](https://www.raibaz.it/).

## The rules

| Time          | Verdict |
| ------------- | ------- |
| 05:00 – 11:00 | SÌ      |
| 11:00 – 12:00 | MAH     |
| 12:00 – 20:00 | NO      |
| 20:00 – 02:00 | NO!     |
| 02:00 – 05:00 | BOH     |

New Year's Day, April Fools', Ferragosto and Christmas have their own opinions.

Tap anywhere to hear it again. Don't tap too much.

## Ask anything

Any question gets a straight answer:

```url
https://cappuccino.sirlisko.com/?q=Where do Italians stand on pumpkin spiced caramel oat milk?&name=Simon
```

`name` is optional.

## Development

One `index.html`, no build step, no dependencies. Open it in a browser, or:

```sh
npx serve .
```
